# 패널 UI 규칙

- 관제의 일반적인 사용법을 별도 문단·빈 상태 안내·토글로 반복하지 않는다. 입력 안내는 입력창 placeholder로 충분하다.
- 사용자가 설명을 제거해 달라고 하면 더 짧은 설명으로 바꾸거나 다른 영역에 다시 넣지 않는다.
- 대화가 없으면 빈 대화 박스를 숨긴다. 실제 응답 진행·결과·오류·대상 정보는 필요한 위치에 표시한다.
- 관제의 고정 위치 선택은 접기·창 크기·보기 변경으로 이동시키지 않는다. 반응형 위치 전환은 사용자가 `자동`을 선택한 경우에만 한다.
- 게임 같은 경험은 안정된 공간·선택의 반응·실제 진전의 축적으로 만든다. 레이더·번호 미션 대시보드·양피지·모험가 테마로 바꾸지 않는다. 세션은 기존 Claude/Codex 등 공급자 아이콘으로 표시한다. 픽셀 사람·캐릭터를 추가하지 않는다. 경험치·레벨은 제거하며 현재 작업의 중요도를 P0/P1/P2로 표시한다. P0를 단순 대기·실패 상태에서 자동 추정하지 않는다.
- 과거 기록을 볼 때 현재 작업의 메모·상태·지시 기능을 섞지 않는다. 현재로 명시 복귀한 뒤 정확한 대상과 최신 상태를 확인한다.
